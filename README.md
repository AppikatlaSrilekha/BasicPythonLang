**Text Classification and Personalized News Recommendation Using Newsgroups Dataset**
This Python project leverages machine learning to perform text classification on the 20 Newsgroups dataset and offers personalized news recommendations based on user interests. The project includes the following key features:

1. _Dataset Loading and Preprocessing:_
Utilizes the 20 Newsgroups dataset, a popular dataset for text classification tasks.
Preprocesses text data using TF-IDF vectorization, selecting the top 10,000 features.

2. _Model Training and Evaluation:_
Implements a Multinomial Naive Bayes classifier to categorize articles into 20 different groups.
Evaluates the model's performance through accuracy score and detailed classification reports.

3. _Personalized News Recommendations:_
Provides recommendations by calculating cosine similarity between user-defined interests and articles in the test set.
Displays the top 3 most relevant articles according to the user's preferences.

4. _Visualization:_
Visualizes the distribution of news categories in the dataset using a pie chart, offering insights into the model's predictions.
This project demonstrates a practical application of machine learning for content personalization, with a focus on text classification and user-centric recommendations.
